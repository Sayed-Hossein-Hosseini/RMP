# Research method and presentation

> A collection of academic writing artifacts, coursework deliverables, and professional documentation completed for the **Research Methodology** course.

---

## 📌 About This Repository
This repository serves as an open-access archive of practical deliverables produced during the **Research Methodology** coursework. The primary goal of sharing this collection is to showcase end-to-end coursework practices, spanning academic typesetting, proposal structuring, and comprehensive CV design.

## 📂 Deliverables Overview

### 1. 📄 Curriculum Vitae (`Curriculum Vitae (CV)/`)
- **Focus:** Dual-purpose resume design bridging academic milestones and professional/industry experience.
- **Key Artifacts:** Structured profiles highlighting education, research background, technical competencies, and applied project experience.
- *Note:* Represents the original CV prepared as part of the course assignment.

### 2. 📑 $\LaTeX$ Documentation (`LaTeX/`)
- **Focus:** Technical and scientific document typesetting.
- **Key Artifacts:** Formatting exercises covering mathematical notation, tabular environments, citations/bibliography handling, and academic paper structures.

### 3. 💼 Proposal Formulation (`Proposal/`)
- **Focus:** Development of a formal business/technical proposal following rigorous research and feasibility guidelines.
- **Key Artifacts:** Problem statement, market/technical scope, methodology, timeline estimation, and resource allocation.
